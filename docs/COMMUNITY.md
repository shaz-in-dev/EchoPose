# Community Setup Guide

This repository includes files and workflows for community scaling.

## Enable GitHub Discussions (one-time setting)

1. Open repository Settings -> General.
2. Scroll to Discussions and click Enable.
3. Create categories:
   - Announcements
   - Q&A
   - Ideas
   - Show and Tell

## Recommended Maintainer Cadence

- Weekly roadmap update post.
- Monthly benchmark report post.
- Quarterly architecture review linked to ADR updates.

## Contributor Onboarding

- Point new contributors to `README.md`, `docs/README.md`, and `docs/adr/README.md`.
- Require benchmark evidence for performance claims.
