# Architecture Decision Records (ADR)

ADRs capture important technical decisions and their consequences.

## Naming

Use `ADR-XXXX-short-title.md` where `XXXX` is a 4-digit sequence.

## Status Values

- Proposed
- Accepted
- Superseded
- Deprecated
