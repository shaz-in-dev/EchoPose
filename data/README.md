# Data, Baselines, and Proofs

This directory stores reproducible benchmark artifacts.

## Layout

- `baselines/` - benchmark result snapshots and reference metrics
- `proofs/` - proof-like validation artifacts for claims

## Rules

- Commit only lightweight metadata and summaries.
- Keep large binary files in external storage and link from manifest files.
- Every public claim should map to a script and a file in this folder.
